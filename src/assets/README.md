# Wilson Orb Assets

These are the authentic visual assets from the original wilsonaibro foundation.

## Required files (copy from jennifercox726-ux/wilsonaibro)

- `wilson-fluid.png`  (primary Orb texture)
- `wilson-fluid.webp` (optimized)
- `wilson-fluid.gif`  (animated version)
- `wilson-opal.jpeg`  (opal reference)

## Source

https://github.com/jennifercox726-ux/wilsonaibro/tree/main/src/assets

After placing the files here, the Orb will load them locally instead of the remote URL.
