# Wilson Portfolio Manager — Privacy Policy

1. **Data Collection**  
   The software does not collect, store, or transmit personal data to any third party controlled by the author.  
   API keys and credentials remain on the user’s machine and are used only to authenticate with services the user configures (Alpaca, Tavily, Google Gemini).

2. **Third-Party Services**  
   The software may send requests to:
   - Alpaca (order and account data)
   - Tavily (news search)
   - Google Gemini (sentiment analysis)  

   Each of those services has its own privacy policy. The user is responsible for reviewing them.

3. **No Analytics or Tracking**  
   The software contains no analytics, telemetry, or tracking.

4. **Logs**  
   Any console or file logs stay on the user’s machine and are not transmitted.

5. **Changes**  
   This policy applies to the current version of the software. Material changes will be noted in the repository.

6. **Contact**  
   For questions about this policy, contact the repository owner.
